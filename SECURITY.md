# 🔒 Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, **do not open a public GitHub issue**. Please report it privately:

- **Email:** alimaandev@gmail.com
- **Response time:** Within 72 hours
- **Process:** We'll confirm receipt, investigate, and release a fix as soon as possible.

## Responsible Disclosure

We ask that you:

1. Report the vulnerability privately (see above).
2. Give us reasonable time to fix it before public disclosure.
3. Do not exploit the vulnerability or access unauthorized data.

## Recognition

We maintain a list of security researchers who have responsibly disclosed vulnerabilities (with their permission). If you'd like to be credited, let us know in your report.
