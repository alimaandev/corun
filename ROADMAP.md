# Roadmap

## ✅ Completed (v1.0 — v1.1)

- [x] 12-level 3D story mode with diegetic code editor
- [x] 52 hand-crafted JavaScript puzzles across all levels
- [x] Procedural soundtrack (Web Audio API, 12 level-specific presets)
- [x] Particle effects (burst/trail system with 500-particle pool)
- [x] Touch controls (virtual analog joystick + interact button)
- [x] 3D scene polish (7 scenery types, starfield, sky planes, NPC/player idle bobbing)
- [x] User-generated content (PuzzleEditor, CommunityPuzzles, URL sharing)
- [x] Speed Run (60s countdown) and Survival (3 lives) game modes
- [x] Social features (Web Share API, puzzle sharing, leaderboard)
- [x] Accessibility & i18n (focus traps, ARIA, 3 locales EN/ES/FR)
- [x] PWA polish (InstallPrompt, OfflineIndicator, enhanced manifest)
- [x] Performance optimization (code-split chunks, offscreen canvas, lazy loading)
- [x] Guest/demo auth mode (auto-detects missing Auth0 env vars)
- [x] CI/CD with GitHub Actions + semantic-release
- [x] Branch protection with required `build` status check

## Short-term (v1.2 — v1.4)

- [ ] Sound effects toggle (mute/unmute) in HUD
- [ ] Keyboard shortcut hints overlay (press `?`)
- [ ] Confirmation dialog before leaving an active game
- [ ] Challenge difficulty indicators (★☆☆ / ★★★)
- [ ] Loading skeleton for Level Select
- [ ] SEO: automatic sitemap generation, per-page meta tags
- [ ] OG image / social preview card (1200×630)
- [ ] GitHub issue templates (bug report + feature request)
- [ ] PR template with checklist

## Mid-term (v1.5 — v2.0)

- [ ] More levels — community-sourced puzzle pack
- [ ] Level editor enhancements — visual scene builder
- [ ] Multiplayer races — solve challenges against other players in real time
- [ ] Enhanced leaderboard — seasonal resets, tier rankings
- [ ] Achievement system — badges for milestones
- [ ] Full save-state sync across devices via Supabase
- [ ] Plugin API — third-party challenge integrations
- [ ] Dark mode variations beyond current theme

## Long-term (v2.0+)

- [ ] Procedural level generation
- [ ] Corun Creator program — featured community challenges
- [ ] Mobile native app (React Native)
- [ ] Advanced analytics — track learning progress per topic

---

*This roadmap is a living document. Priorities may shift based on community feedback.*
